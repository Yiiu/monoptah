1. 改造 Native 回合回执，原子写入保底摘要，快速模型结果按回合比较后写入。
2. 从结束事件启动有上限的摘要任务，将读取接口交给 Tree 和 Mono。生成失败不会影响已完成回合。
3. 接入设置中的工作树清理成功回调和本地 Git 合并扫描。应用归档前复查会话工作状态和工作树归属。

5. 用 `cargo +1.98.1 ncheck --all-targets -p monocode-gpui` 和相关 Rust 测试验收。使用隔离数据验证实际界面。
