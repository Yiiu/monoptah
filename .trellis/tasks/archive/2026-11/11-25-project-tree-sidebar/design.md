# Tree 布局设计

以父任务和 Ryugi 定稿为界面依据。Tree 继承 Focused 的窗口栏、右侧工具和 Peek 生命周期。

- `project_tree.rs` 读取 Shell 的轻量会话索引和 AgentStatus。项目分类按 Classic 的持久化顺序生成。GPUI ListState 只渲染可见行。
- 同一会话只进入优先级最高的栏目。过滤命中项保留其祖先，项目计数排除归档。工作树按会话的保存路径分组。右侧工具和标签页由已有打开会话的路径切换。
- 关联本地项目的云会话归入该项目的主目录。打开时采用本地的标签页和右侧面板范围，远程路径仍用于执行。
- 主视图和收起栏使用相同项目分类、主题色和 Mono 名册。点击收起栏中的项目设定列表滚动目标，再打开 Focused 的 Peek 外框。
- 会话菜单复用 Shell 原有动作。文件夹变更按来源项目保存。项目与分组共用 Classic 的顺序及拖拽控制。
- 项目、项目组、会话文件夹和同级会话按可见标题定位。拖动时标题在侧栏视口内持续跟着指针，子行随其移动，经过的同级项让出空位。松手后按标签页的节奏滑入新位置。项目排序限于同一分组、Pinned 区或未分组区，文件夹排序限于所属项目。
- 手工拖动过的会话在同一工作树、文件夹或 Pinned 区内记住顺序。未排序的新会话仍按最近活动显示。横向拉出排序栏或拖到其他区的文件夹时，使用原有的文件夹或分屏落点。
- 摘要服务由 2b 提供。Mono 启动归属与头像由第 3 期提供。Tree 模块读取这两项数据。
