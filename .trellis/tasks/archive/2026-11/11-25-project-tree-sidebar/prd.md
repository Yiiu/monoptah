# 第 2a 期：Tree 布局

## Goal

在 Native 的外观设置新增 Tree 选项。项目、工作树和会话可在同一侧边栏浏览，并保留 Focused 的标签页和右侧工具。

## Requirements

- 项目顺序、Pin、分组、会话文件夹、提醒和筛选与现有布局共用数据。
- 常驻 Needs you 队列汇总跨项目的待处理请求。键盘和点击打开正确的项目与工作树。
- 收起后保留 48 像素状态栏，点击项目头像打开滑出树并定位到该项目。

## Acceptance Criteria

- [ ] 项目下按 Pinned、Reminders、文件夹、工作树排列，归档集中显示在底部。
- [ ] 行展示原问题、运行步骤或未读摘要，项目和工作树汇总来自统一会话状态。
- [ ] 展开与收起使用同一项目顺序，左侧保留现有项目和会话菜单、选择与拖拽。
