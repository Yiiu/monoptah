# 第 2b 期：进展摘要与归档

## 目标

在 Tree 中扫描已完成工作的进展，并从主视图收起已经合并或清理的工作。

## 需求

- 每轮结束生成一行进展摘要，说明完成的工作或仍需用户做的事。未读完成的会话显示在标题下。
- 可从行菜单手动归档和恢复。工作树清理成功或分支确认合并后自动归档相关会话。
- 已归档会话保留在 Tree 底部的「Archived N」，从实时项目计数中排除。

## 验收

- [ ] 读取历史会话可恢复最新回合的摘要。
- [ ] 重试或迟到的生成结果不会覆盖较新的回合。模型不可用时显示保底摘要。
- [ ] 同一归档事件只处理一次。恢复后的会话可以保留在主视图。
- [ ] 工作树证据只影响对应且已结束的会话，草稿和进行中的会话继续显示。
