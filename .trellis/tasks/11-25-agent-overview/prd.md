# 多任务总览：agent 状态与项目树侧边栏

## Goal

用户同时开发多个项目、并行修多个 bug 和需求，目前必须逐个点进会话才知道每件事的进展。目标是让每件事的状态在侧边栏一眼可见，需要用户处理时能及时注意到；同时让 Mono 派出去的活可见、可控。

只做 Native（GPUI）应用。设计稿：`.ryugi/artifacts/artboard/agent-overview-sidebar/`（Ryugi 画板「Monoptah 多任务总览：项目树侧边栏」）。

## Principles

- **全部自动、对所有人通用**：状态、计数、已读、归档都由固定规则推出。不为个人习惯新增设置项或开关。
- **不强制收尾**：完成的条目想留多久留多久，没有必须点的"验收"动作。
- **状态取自真实事件**：从 provider 事件和进程推出，不靠 agent 自己汇报，避免"Working"卡住不灭。
- **适用于所有 provider**：Claude、Codex、Hermes（ACP）等。没有某种能力的 provider 自然少一种状态，不做特例 UI。

## Requirements

### Agent 状态模型（每个 agent 会话一份）

按紧急程度从高到低：

| 状态 | 条件 | 显示 |
|---|---|---|
| 等我 | 等用户回答问题或批准 | 两行，第二行是 agent 的原问题；进顶部「等我」队列 |
| 在跑 | agent 正在输出这一轮 | 一行，右侧显示当前步骤 + 时长（如「运行测试 · 4m」，约 15 秒刷新一次） |
| 后台等待 | 这一轮已结束，但还有会把它叫醒的后台工作（子 agent / workflow / monitor，不含 ambient） | 一行，右侧显示「等 N 子任务」，不转圈 |
| 完成 | agent 停下 | 右侧 ✓ + 多久前。未打开过时：标题加粗、左侧绿点、下面一行摘要；打开过后自动变成一行、变暗 |

- 后台 shell 命令（dev server、watch、后台测试）**不算**在跑，只显示一个 `dev` 类标签，悬停可看命令。
- 打开过会话就算看过（已读），不需要任何按钮。

### 侧边栏：第三种可选布局「项目树」

- 设置 → 外观 → Layout 从 Classic / Focused 扩展为 Classic / Focused / **Tree**。
  - Tree 保留 Focused 的工作区标签页和右侧面板。
  - 左侧的项目切换栏和会话列表换成一棵项目树。
- 标签页和右侧面板沿用 Focused 现有的逻辑，不做改动。
  - 两者都只显示"当前项目 + 当前 worktree"的内容（`shell/title_tabs.rs` 的 `scoped_tabs`）。
  - 在树里点击另一个项目或 worktree 下的会话，就会切换到那个项目和 worktree：标签页和右侧面板随之切换，效果等同于在 Focused 里先用项目切换栏、再用 worktree 切换器。
  - `Ctrl J` 打开下一个等我的会话时也是同样的切换。
- `Ctrl/Cmd+Shift+L` 和菜单「Toggle Layout」按 Classic → Focused → Tree 循环切换。不新增侧边栏内的切换器。
- 新用户的默认布局不变；"试试新布局"的提示不推荐 Tree。现有两种布局的行为保持不动。
- Mono 的像素小人在 Tree 里保留：
  - Mono 名册放在树的顶部（「等我」队列下面、项目上面），沿用现有名册组件和它的状态动画（空闲 / 工作中 / 等你）。
  - Mono 派出的会话行，用该 Mono 的像素小人做标记。
  - 会话内容里子 agent 的像素小人不受影响。
- **结构**：项目 → worktree/分支 → agent，状态按 **agent 行** 算（同一个 worktree 里可以并行做不相关的事）。
  - worktree 行只显示其中最紧急的状态点，并用暗色小字显示 diff（+/−）。
  - 项目只有主目录时不显示 worktree 层，会话直接挂在项目下；有多个带会话的 worktree 时才显示 worktree 行。
  - 远程项目没有 worktree 层。
  - Tree 布局里不需要 worktree 切换器。新建 worktree 放到项目行的菜单里。
- **项目展开后的顺序**：Pinned（钉住的会话）→ Reminders → 文件夹 → 各 worktree（剩下的会话）。
  - Pinned、Reminders 和文件夹里的会话不在 worktree 下重复出现，行尾标出所在分支。
  - worktree 里的会话按最近活动排序，不加日期小标题。
  - 编排器的子 agent 和 Operator 发起的会话作为第 4 层，默认折叠，只显示数量。
- 顶部常驻「等我」队列：跨所有项目；为 0 时收起成一行；`Ctrl J` 打开下一个等我的会话。
- 项目行三色计数：等我 / 在跑（含后台等待）/ 未读的完成；为 0 时不显示；比项目名小、更暗；项目折叠后仍可见，里面有在跑的时头像带蓝环。
- 行密度：等我、未读完成占两行，其余一行。
- 视觉规格沿用现有侧边栏：
  - 列表内边距 6px，行与行之间 2px，行圆角 6px。
  - 悬停填充为前景色 5% 透明度，选中为 10%（半透明前景色，不用不透明的灰色）。
  - 子级连线是一条竖线，到最后一个子项时圆角弯入；复用现有编排器连线的 `rail_color` 和弯角画法。
- **透明度、玻璃效果和浅色主题**：所有新界面（树、「Needs you」队列、收起状态栏、滑出面板、菜单、标签页上的状态标记）一律使用 `theme.rs` 的主题函数，不写死不透明的颜色。具体要求：
  - 侧边栏和收起状态栏的底色用 `shell_fill()`，跟随「侧边栏不透明度」设置；正文区用 `pane_fill()`，跟随「玻璃正文」设置。
  - 悬停和选中的填充、计数、连线都用半透明前景色（`content(a)`、`rail_color()`）。
  - 状态色用 `warning_color()`、`success_color()`、`danger_color()`，浅色主题会自动换成更深的色值。
  - 滑出面板和菜单沿用现有的浮层底色（`floating_fill()` 等）。
  - 验收要覆盖三种外观：深色玻璃（默认侧边栏 85%、正文 28%）、深色不透明、浅色主题。
- **标签页**：沿用 Focused 现有的样式和逻辑（高 27px、6px 圆角、24×20 图块），只有**状态图标**一处改动。标签页和树里的会话行共用同一个图标组件，所以 Focused 的标签页也会一起换成新图标。
- **状态图标（定稿：方案 A + R1）**：
  - 图块始终显示 provider 本身的样式：Claude 是橙色渐变，Codex 是蓝色渐变，上面是矢量 logo。图块带顶部高光和 1px 边缘。不再把整个图块换成灰底加状态符号。
  - 静止状态用右下角的角标表示：
    - 等你：琥珀色实心点
    - 后台等待：空心蓝圈
    - 完成未读：青色实心点
    - 角标尺寸为标签页 8px、会话行 7px；外面描一圈和它所在底色相同的边（2px 或 1.5px），这个底色随未选中、选中、悬停、侧边栏、浅色主题而变。
  - 「在跑」是唯一会动的状态：一道光沿图块外沿绕圈（周期 1.6s），底下有一圈 24% 透明度的淡蓝色底轨。光圈画在图块外面，不占布局，所以在跑的标签标题和其他标签对齐。光圈与图块同心（以图块边缘为基准计算）。标签页：图块 24×20、圆角 5，间隙 1，光圈宽 1.5，光圈内圆角 6、外圆角 7.5。会话行：图块 16×14、圆角 4，间隙 1，光圈宽 1.25，光圈内圆角 5、外圆角 6.25。在跑时去掉图块底部的投影，让四边间隙看起来一样。开启"减少动态效果"时光圈保持静止。
  - 完成未读只显示角标，不再另加绿点。
  - 由 Mono 派出的会话，在标题后面跟一个 10px 的 Mono 像素小人。
  - worktree 行的汇总状态用同色系的点表示：琥珀、蓝、青。
- 点击任意行直接进入会话；不做预览浮层。
- 归档：可选，悬停或右键操作；分支合并或 worktree 清理后自动归档；归档后收进底部「已归档 N」，不计入计数。

### Tree 布局的功能对齐（不丢现有功能）

- **项目头像**：用现有的像素小人（10 种 8×8 精灵图，手动选或自动算；颜色和 logo 照旧；远程项目显示地球图标）。
  - 修复：没手动选的项目统一按**文件夹名**算头像（目前 Classic 项目栏按文件夹名，其他地方按完整路径，同一个项目会出现两个不同的小人）。
- **项目层**：
  - Pinned 区放在树顶部。
  - 分组显示为可折叠的小标题，保留颜色和小人。
  - 拖拽排序只在所在区域内进行，分组本身也能拖动。
  - 保留"移到分组"、上移 / 下移快捷键，以及项目右键菜单的全部项目：新建会话、新建 worktree、Pin、移到分组、外观、静音、在编辑器中打开、在文件管理器中显示、归档、删除。
  - 和 Classic **共用同一份数据**（`project_rail_pinned`、`project_rail_groups`、`project_rail_assignments`、`projects` 的顺序）。
- **会话层**：以下功能全部原样保留：
  - Pin、文件夹（新建、拖进去、拖到另一个会话上新建、颜色、重命名）、提醒；
  - 重命名、归档、删除、关联 issue/PR、复制 ID、云端操作；
  - 多选和批量操作、右键菜单、紧凑行的悬停预览。
- **筛选**：沿用现有菜单（已归档 / 状态 / 时间 / Provider），命中会话的上级行保留可见。不新加搜索框，搜索用 ⌘K。
- **侧边栏外框**：
  - 导航行（Search、Today、New、Inbox、Notes、Automations、Contributors）放在最上面，显示和隐藏的选项沿用 Focused 的。
  - Tree 里不显示 Live agents 卡片，也去掉 Focused 顶部的项目切换器和底部的项目图标条。
  - 宽度拖拽、⌘B 收起、收起后从左边缘滑出，这些保留。
- **收起状态（Ctrl/Cmd+B）**：固定一种行为，不加设置项。
  - 收起后变成 48px 的状态栏，从上到下：展开按钮、导航图标（带计数或小点）、琥珀色「Needs you N」（点击等同 Ctrl J）、Mono 像素小人（带状态点）、项目像素小人。
  - 项目小人的顺序、Pinned 和分组色条与展开时一致。右下角的点表示项目里最紧急的状态（等我 > 在跑 > 未读完成），有在跑的会话时再加一圈蓝框。悬停显示该项目的计数。
  - 点击某个项目小人，整棵树从左侧滑出并滚到该项目；点会话进入或者鼠标移出面板后，树自动收回。鼠标贴到窗口左边缘也会滑出（沿用 Focused 的行为）。面板上的图钉或 Ctrl/Cmd+B 可以把树固定展开。
- **快捷键**：⌘⇧↑/↓ 按树的顺序切换会话，⌘⇧←/→ 跳到上一个 / 下一个项目，⌘1–8 仍然切换标签页。

### 进展摘要

- 每轮结束时，用快速模型为该 agent 生成一行摘要（做了什么 / 需要你什么）。显示在未读完成行的第二行。

### Windows 系统提醒（延期）

第 1 期交付 R1–R5。Windows 系统提醒保留为独立后续任务。

- 窗口不在前台时，「等我」触发 Windows 系统通知：写清项目、会话和 agent 原话；点「打开」直接进入会话；未处理的通知留在通知中心。
- 任务栏图标叠加「等我」数字角标；有新的等待时闪烁，直到窗口回到前台。
- 声音在 Windows 上可用（系统提示音）。
- 完成只更新角标，不弹通知。窗口在前台并且正在看那个会话时不弹通知。

### Mono

- 修复：选了一张选项卡后，其他所有选项卡都会失效。改为每张卡独立判断是否已回答。
- 决策统一用问题卡：可多选、带「其他」自由填写、选项不限 4 个。Mono 的提示词要求它在需要用户决定时使用卡片。Mono 的待决定事项进入「等我」队列。
- Mono 派出的会话默认出现在项目树里，挂在对应 worktree 下，并带上该 Mono 的像素小人标记。
- Mono 总览显示计划清单（N 完成 / N 在跑 / N 等你），状态直接取自它派出的会话。
- 二期：Mono 定期巡检、汇总进展；没有变化时不打扰用户。

## Acceptance Criteria (cross-child)

- [ ] 只挂着 dev server 的会话不再显示 Working；后台任务从列表消失后状态不会卡住。
- [ ] 同一套状态在侧边栏、项目计数、「等我」队列、通知和 Mono 计划清单里一致。
- [ ] 没有新增任何个人化设置项。
- [ ] 现有两种布局（Classic、Focused）的行为不变；Tree 是第三个可选项，可以通过设置、菜单和快捷键切换。
- [ ] Tree 布局里，Mono 的像素小人和它们的状态动画仍然可见。
- [ ] Classic 和 Focused 里现有的每项左侧功能，在 Tree 里都有对应入口（见「Tree 布局的功能对齐」）；Pin、分组和顺序在 Classic 和 Tree 之间保持一致。

## 实现与验证

- 五个子任务的代码保存在 `.worktrees/agent-status-core` 的 `fix/agent-status-core` 分支工作树中。
- Windows `native-dev` 下通过 46 项 Core 定向回归和 32 项 GPUI 定向回归。通过全目标类型检查和 Clippy。Clippy 仍报告原有 Windows 代码的告警。
- 自动化覆盖回合完成与唤醒、已读和摘要的存储、Git 合并证据、布局兼容和三种外观下的收起栏、跨项目和工作树切换、云会话的本地标签页范围、决策卡兼容及巡检分批。
- 真实提供商、云端联调、桌面目测和 Linux CI 尚未验证。Windows 系统提醒按原安排延期。
